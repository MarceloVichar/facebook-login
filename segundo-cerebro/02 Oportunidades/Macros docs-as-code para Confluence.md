# Macros docs-as-code para Confluence

Voltar para [[Ranking]].

> [!info] Condicional: viva, mas não avançou (25/35)
> Construção de dias e comprador em dólar, mas o teto de receita é baixo e já existe um concorrente Forge forte.

## O que é

Um app Forge que renderiza Mermaid, PlantUML, OpenAPI/Swagger e Markdown a partir do código da página ou de URLs do Git, posicionado como seguro diante do fim do Connect.

## Comprador

Times de engenharia em Confluence Cloud.

## Evidências

- Mermaid: Stratus (Connect, última versão em 2023) 4,02★, 6.302 instalações, US$ 60/ano para 15 usuários; Mermaid Chart (grátis) 2,94★, 4.105; visualizador grátis da Atlassian Labs 2,99★, 7.600 ([API](https://marketplace.atlassian.com/rest/2/addons?hosting=cloud&text=mermaid&limit=50&withVersion=true)).
- OpenAPI: incumbentes em Connect, parados desde 2024 (2.869 e 1.211 instalações) ([API](https://marketplace.atlassian.com/rest/2/addons?hosting=cloud&text=swagger&limit=50&withVersion=true)).

## Concorrentes

Just Add+ (Forge, pago), 4,25★, 8.072 instalações.

## Riscos

- Teto baixo: US$ 30–60/ano para 15 usuários e US$ 200–400 para 100.
- Um macro só de Mermaid é armadilha (visualizador grátis da Atlassian Labs).
