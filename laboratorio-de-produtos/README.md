# Laboratório de Produtos

Este repositório reúne a pesquisa, as decisões e o código para encontrar e validar um produto de software com custo zero.

- **Segundo cérebro:** a pasta [`segundo-cerebro/`](segundo-cerebro/) é um vault do Obsidian. No Obsidian, use "Open folder as vault" e escolha essa pasta.
- **Testes em andamento:** veja [`segundo-cerebro/04 Execução/Carteira de testes.md`](segundo-cerebro/04%20Execução/Carteira%20de%20testes.md).
- **MVPs:** ficam em [`apps/`](apps/).
- **Claude:** o arquivo [`CLAUDE.md`](CLAUDE.md) dá contexto ao Claude Code. As instruções para criar um Claude Project estão em [`docs/claude-project.md`](docs/claude-project.md).
